# Apex Investment — GitHub Starter

A responsive investment-style front-end inspired by the dark navy/gold visual direction requested for Apex Investment.

## Included

- `index.html` — complete homepage
- `style.css` — responsive dark/gold design
- `script.js` — mobile navigation + illustrative market chart
- `assets/apex-ad.mp4` — included promotional demo video
- `assets/apex-ad-poster.png` — video poster
- `README.md` — setup notes

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Replace before publishing

1. Replace the placeholder email, phone number and address.
2. Replace the demo investment-plan descriptions with accurate, legally approved information.
3. Replace the included promotional video if you have your own approved advert.
4. Replace the illustrative market figures/chart with data from a licensed provider if you intend to display live market information.
5. Add your real authentication/backend.
6. For real payments, use a secure server-side integration with your payment provider. Never commit secret API keys to GitHub.
7. Add accurate privacy policy, terms, risk disclosures, company information and any required licensing/regulatory information.

## Important

This repository is a front-end template. It does not itself process investments, guarantee returns, or represent that Apex Investment is licensed or regulated.
